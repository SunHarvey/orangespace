# 分阶段交付与证据边界

接手基线：`main` / `38d9739`。不改写已有历史，不添加项目许可证。

## 第一阶段：受保护启动链（进行中）

- Windows SCM 服务、显式 ACL 的本地 IPC、通过操作系统令牌确定调用者。
- 节点登录从认证回复取得用户身份；可信配置将 API 地址、节点身份、证书信任和授权联系起来，不能凭用户输入相同 UUID 获得信任。
- 凭据不进入命令行、环境、日志或明文持久化文件；持久化使用 Windows 用户绑定保护。
- 每沙盒 helper 生命周期绑定完整 `(user_id, sandbox_id, node_id, generation, tunnel_id)`，独立停止和回收。
- CEF 固定版本、现代 bootstrap/client.dll ABI、非空 sandbox 信息和版本/hash 校验的独立构建验证。
- **退出条件**：真实 Windows 上服务安装/停止、另一用户拒绝、认证登录、凭据隔离、helper 回收、CEF sandbox 构建证据。模块通过不等于本阶段全部完成。

## 第二阶段：强制联网数据面（未开始）

WFP TCP 重定向、原目标恢复、UDP 捕获/吸收/回注、受管 DNS、IPv4/IPv6/loopback、浏览器子进程身份；每沙盒独立 TUIC、连接代次与迟到回包隔离。组件失效关闭。地址/证书/授权来自可信配置或已认证控制面。

## 第三阶段：真实 Windows 网络隔离（未开始）

深圳/广州双节点并发、多用户共用节点、相同连接编号、旧回包、断网、节点切换、服务/helper 崩溃。保存抓包和进程绑定证据，证明本机直连及 DNS 泄漏不存在。前两阶段编译、状态机和 TUIC 回环通过均不能替代本阶段。

**只有本阶段完整通过后，才讨论开放浏览器；不存在 ready 配置、unsafe 开关或禁用 Chromium sandbox 的提前通道。**

## 第四阶段：完整浏览器与文件桥（未开始）

完整标签、弹窗归属、扩展、WebRTC、登录持久化、下载管理、个人文件面板、原会话认证/POST/blob 下载和网页文件选择。下载先到沙盒隔离临时区，原节点服务器提交成功才完成；上传先从原节点下载再交给原网页。任务节点在创建时固定；关闭/切换保留本机数据和任务，删除只清本沙盒本机数据，不删除 Linux 共享个人区。

## 第五阶段：分发（未开始）

安装卸载、驱动签名/分发、日志脱敏和复现说明。沿用橙色主题和 `assets/brand/orangespace-logo-approved.png`，生成并验证窗口/任务栏/安装器图标，不重新设计品牌。

## 提交与验收

仅配置当前仓库的 SunHarvey 作者/提交者、指定邮箱和已有 SSH 签名/推送 key；推送前核验身份与签名，推送后读取 GitHub 提交的账号和 Verified 状态。缺少指定签名环境不生成替代 key。每个交付必须列出代码、真实执行的测试、未验证项，不将 CI 编译描述成完整产品验收。
